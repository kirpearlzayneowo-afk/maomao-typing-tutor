# 猫猫戳戳打字通

一个披着学校机房外壳的本地打字练习页。

**[在线体验](https://kirpearlzayneowo-afk.github.io/maomao-typing-tutor/)**

> 一句“给我做个金山打字通算了”之后，它真的出现了。

本项目是独立制作的非官方个人作品，与金山软件、4399、Apple、Wacom 无隶属、授权或合作关系；文中名称仅用于说明项目灵感、个人经历与幽默表达。

## 可以做什么

- 用可视键盘标出下一个目标键
- 练习简短的英文词句
- 使用中文输入法完成中文小句
- 切换四套可持续扩展的 DLC 语言包
- 在本机记录今日与累计通关次数
- 断网使用，无需账号，不上传输入内容

## 使用方法

下载 `index.html`，双击后用浏览器打开即可。所有代码、样式和文字都在这一个文件里。

## 设计原则

- 用状态、进度与操作提示代替评价和安抚
- 每一关结束后由用户决定是否继续
- 不设置倒计时与排行榜
- 输入法合成期间等待选字结束再核对
- 记录只保存在浏览器的 `localStorage` 中

## 文案迭代

v1.2 增加可持久化的 DLC 语言包插槽。首发内容：

- 🖥️ 机房潜伏行动
- 🎨 画室紧急存档
- 🚀 宇宙飞船发布会
- 🐈 猫猫管理员权限

语言包按独立数据对象组织，后续可以继续增加台词与主题，无需改写练习逻辑。季票永久免费，支架包含在包装盒内。

v1.1 将“减压许可”式表达改为“机房任务＋冷面荒诞”：界面直接说明发生了什么、下一步怎么做，不先假设用户做得不够，再给予豁免。
