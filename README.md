# 猫猫戳戳打字通

一个不用追求速度、没有排名，也不会因为错字扣分的本地打字练习页。

**[在线体验](https://kirpearlzayneowo-afk.github.io/maomao-typing-tutor/)**

> 一句“给我做个金山打字通算了”之后，它真的出现了。

本项目是独立制作的非官方个人作品，与金山软件、4399 无隶属、授权或合作关系；文中名称仅用于说明项目灵感与个人经历。

## 可以做什么

- 在可视键盘上慢慢寻找按键
- 练习简短的英文词句
- 使用中文输入法完成中文小句
- 在本机记录今天和累计完成的小行
- 断网使用，无需账号，不上传输入内容

## 使用方法

下载 `index.html`，双击后用浏览器打开即可。所有代码、样式和文字都在这一个文件里。

## 设计原则

- 打完一小行就算完成
- 低头找键位完全没关系
- 没有倒计时、排名和惩罚
- 输入法还在选字时不抢着判错
- 记录只保存在浏览器的 `localStorage` 中
